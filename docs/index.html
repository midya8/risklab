Finite evidence. Stated limits.
At most 15 supplied tree nodes, eight terminal leaves, four decision nodes, depth six and 64 full deterministic policies. Terminal losses only. Costs are losses: lower is better. One confidence alpha applies to every chance node. This is not an unrestricted risk-sensitive MDP solver.
Static CVaR is law-invariant. Nested CVaR depends on information grouping and need not be above static CVaR. Backward selection gives locally optimal nested continuations; other root-optimal ties can be locally worse because tail risk is not strictly monotone.
Native Python uses tail filling. Its separate checker enumerates bounded risk-envelope vertices and replays full paths. The browser uses BigInt rationals and threshold minimization. Shared assumptions and schema mean agreement is evidence, not formal proof. Display bars use rounded coordinates; exact tables and certificates decide all ties.
Original teaching controls, including seeded development-selected counterexamples. No held-out benchmark, learning, new algorithm or guarantee that a supplied tree matches the world. Derivation, attribution and source ledger ↗
